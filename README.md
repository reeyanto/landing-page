# Column — Modern Fintech Landing Page

A developer-first banking infrastructure landing page built according to the **Column Style Reference** (`DESIGN.md`).

## Features
- **Design System**: Deep navy ledger (`#111a4a`), near-white canvas (`#f6f6f8`), and Signal Orange (`#ec652b`) accents.
- **Typography & Components**: Professional typography hierarchy, floating product mockup widgets, transaction feed cards, and stat rows.
- **Developer Experience**: Interactive code blocks with Seafoam syntax highlighting (`#167e6c` and `#94efb7`).
- **Responsive Layout**: Clean 1200px centered layout with smooth responsive behavior across devices.

## Tech Stack
- HTML5 / Tailwind CSS v4
- Responsive CSS Grid & Flexbox
- Modern Fintech UI / UX patterns
